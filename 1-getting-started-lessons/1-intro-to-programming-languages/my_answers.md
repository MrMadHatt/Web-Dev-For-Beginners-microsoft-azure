### 1. [CodeRabbitai] - [Code Scanner]

**Purpose:**
    - Scans code that was pushed to GitHub through a text editor or IDE. CodeRabbitai views the code and summarizes any issues, typos, or logic errors that need to be resolved before merging a feature branch to the main branch.
    This allows CodeRabbitai to be used as a "Reviewer" for most PR's.

**Documentation:** [https://www.coderabbit.ai/]

**Workflow Integration:**
    - Fits into a developer's workflow by allowing the AI to resolve any disputable issue that might be found within the code that the developer might have missed or not thought of. 


### 2. [CodeCov] - [Code Analysis]

**Purpose:**
    - Measures how much of the code is covered by tests. Keeps track if test are covering the entire code or only sections of the code.  

**Documentation:** [https://about.codecov.io/]

**Workflow Integration:** 
    - Gives the developer a visual representation of how much of the test actually does the job it was designed to do.


## 3. [Jenkins] - CI/CD Automation

**Purpose:**
    - Jenkins is a server based application that automates the workflow. Jenkins CI/CD pipline automates development workflows from production to release. This program can automatically build an app with predetermined configurations given by the user at any stage of the process and incorporate the user's image into a final product.

**Documentation:** [https://www.jenkins.io/]

**Workflow Integration**
    - Integrates into the building process by allowing a developer to automate the entire developmental process by including specified criteria.
